# Core Modlist — Theme-Focused (NeoForge 1.21.1)

This is a **curated starting set**, not 800 mods. These are high-value mods that actually support the Magic + Exploration + Dungeon + Tech theme and are known to exist / be actively used on NeoForge 1.21.1 as of mid-2026.

Install these first. Verify the instance launches and is stable. Then expand.

## Loader & Essentials
- NeoForge 1.21.1 (latest stable)
- FTB Library
- FTB Quests
- FTB Teams (optional but recommended)
- FTB XMod Compat (for JEI / integrations)
- Architectury API
- Cloth Config
- Balm / Puzzles Lib / Bookshelf / etc. as required by other mods

## Performance & Client
- Embeddium (or Sodium NeoForge equivalent)
- FerriteCore
- ModernFix
- Entity Culling
- LazyDFU / FastLoad equivalents
- Iris / Oculus if you want shaders

## Magic Core
- Ars Nouveau (+ Ars Elemental, Ars Creo, Ars Additions if available)
- Iron's Spells 'n Spellbooks (+ relevant addons / spell extensions)
- Relics / Artifacts / curios-style accessory mods
- Patchouli (if still used by guides)

## Tech Core
- Create (+ carefully chosen addons: Crafts & Additions, New Age, Steam 'n' Rails, Big Cannons only if desired, etc.)
- Mekanism (Generators, Tools, Additions) **or** Oritech as alternative modern tech path
- Applied Energistics 2 (or Refined Storage if preferred)
- Sophisticated Backpacks / Storage

## Exploration & World
- Terralith
- Tectonic (or equivalent terrain)
- YUNG's API + Better Dungeons / Better Strongholds / Better Nether Fortresses / Better Desert Temples / Better Jungle Temples / Better Ocean Monuments / Better End Island / Better Mineshafts
- When Dungeons Arise (+ Seven Seas if available)
- Structory / additional structure mods as desired
- Nature's Compass / Explorer's Compass
- Waystones

## Dungeons & Bosses
- L_Ender's Cataclysm
- Additional boss / structure mods that fit the difficulty curve (test thoroughly)

## QoL & Utility
- JEI (or EMI)
- Jade
- AppleSkin
- Mouse Tweaks
- Inventory Tweaks / Sorter
- Carry On
- JourneyMap or Xaero's Minimap + World Map
- FTB Chunks (if using FTB suite)

## Building / Optional
- Macaw's suite (doors, bridges, roofs, etc.) if desired
- Chipped / Rechiseled
- Farmer's Delight + addons

## Notes

- Do **not** add every Create addon or every structure mod on day one.
- Check for NeoForge 1.21.1 builds on Modrinth/CurseForge before adding.
- Keep a changelog of every mod you add and the date you verified it.
- When the core loop (magic progression + tech progression + dungeon rewards) feels good, then grow the list.

For guidance on pushing toward very large mod counts, see `EXPANDING_TO_800.md`.
