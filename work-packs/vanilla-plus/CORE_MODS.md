# Vanilla Plus — Core mods to install in CurseForge App

Theme: clean baseline. Performance + QoL only. Control instance.

## Recommended
- Embeddium (or NeoForge Sodium equivalent)
- FerriteCore
- ModernFix
- Entity Culling
- JEI or EMI
- Jade
- AppleSkin
- Mouse Tweaks
- Inventory sorter / tweaks
- Xaero's Minimap + World Map **or** JourneyMap

## Optional light content
- Soft decoration mods only if needed for UI testing
- No Create, no Ars, no Cataclysm in this pack

Use this instance to verify that a problem is caused by content mods, not by the launcher or NeoForge install.
