# Create Factory — Core mods to install in CurseForge App

Theme: mechanical automation, factory building, kinetic power.

## Required
- Create
- JEI or EMI
- Architectury API (if required by other mods)

## Strongly recommended
- Create Crafts & Additions (or equivalent power bridge)
- Create: New Age / Steam 'n' Rails / Connected / Deco (pick a few, not all)
- Sophisticated Backpacks or Storage Drawers
- Jade
- AppleSkin
- Mouse Tweaks

## Performance
- Embeddium (or NeoForge Sodium equivalent)
- FerriteCore
- ModernFix

## Optional later
- Applied Energistics 2 or Refined Storage
- Mekanism (only if you want hybrid tech)
- FTB Quests (if you want guided factory chapters)

Start small. Add one Create addon at a time and launch after each.
