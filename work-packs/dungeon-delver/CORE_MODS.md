# Dungeon Delver — Core mods to install in CurseForge App

Theme: exploration, structures, bosses, loot.

## Required / high value
- Terralith
- YUNG's API
- YUNG's Better Dungeons (then other YUNG modules one by one)
- When Dungeons Arise
- L_Ender's Cataclysm
- JEI or EMI

## Strongly recommended
- Nature's Compass / Explorer's Compass
- Waystones
- Jade
- Sophisticated Backpacks
- AppleSkin

## Combat helpers (optional)
- Better Combat or similar only if you want to test combat feel
- Artifacts / Relics for loot toys

## Performance
- Embeddium
- FerriteCore
- ModernFix

Avoid heavy tech trees here. This pack is for dungeon flow and structure density testing.
