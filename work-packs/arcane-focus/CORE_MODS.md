# Arcane Focus — Core mods to install in CurseForge App

Theme: pure magic progression. Minimal tech.

## Required
- Ars Nouveau
- Iron's Spells 'n Spellbooks
- JEI or EMI
- Curios / accessories API if required by the magic mods

## Strongly recommended
- Ars Elemental / Ars addons (one at a time)
- Relics or Artifacts
- Patchouli (if guides need it)
- Jade
- Waystones (optional convenience)

## Performance / QoL
- Embeddium
- FerriteCore
- ModernFix
- AppleSkin
- Mouse Tweaks

## Optional
- FTB Quests + FTB Library for guided spell schools
- Cataclysm later for magical boss targets

Do not add Create/Mekanism here unless you are intentionally testing hybrid synergy.
